# Homepage world assets

- Cherry blossom tree: Grab3D Cozy Nature Kit, https://grab3d.com/models/nature/cherry-blossom-tree/ — CC0 1.0 Universal, verified October 14, 2026. Stored through the project asset service; shared geometry and textures are cached across tree instances.
- Torii gate: custom curved architectural geometry. A suitable direct CC0 GLB could not be retrieved reliably, so no external gate dependency is shipped.
- Mount Fuji: custom radial terrain with irregular snow line.
- Static loading/error landscape: generated artwork, bundled locally.
